# Architecture

Notes is a personal notebook, not a public app. All content is plain markdown files in the `notes/` folder, kept in sync by git, and opened as an Obsidian vault for editing. There is no server and no public site right now; an older static HTML version used to run at notes.heyitsmejosh.com but was taken down and its files are kept only as an archive.

## How it runs

**Obsidian vault:** User opens `notes/` as a folder in Obsidian. The markdown files render with full editing and backlinks. Changes are committed to git manually or via an Obsidian git plugin. No server, no sync service required.

**Static site (archived):** Previously, `pages/` held static HTML renders (built by `scripts/simplify.sh` from `notes/` markdown). The site included a dashboard, searchable note index, and styled note pages. The public site is no longer served.

## File structure

| File/Folder | What it owns |
|---|---|
| `notes/` | All content. Plain markdown files: `master.md` (current state), `ideas.md` (product ideas), `app-scaling.md` (scaling notes), and `reminders.md` (synced from Apple Reminders via `scripts/sync-reminders.sh`, gitignored). No frontmatter, no hidden metadata. `[x]` marks completed tasks, `[ ]` marks open ones. |
| `pages/` | Archived static HTML renders of notes. Generated by `scripts/simplify.sh`, not edited by hand. One `.html` file per note, plus `master.html` for the master note view. Site was deployed to notes.heyitsmejosh.com; no longer served. |
| `assets/css/note-page.css` | Styles for the static note pages (archived). Light/dark theme toggle. Typography and layout for note content. |
| `assets/js/note-page.js` | JavaScript for the static note pages. Renders markdown into HTML (if needed client-side) and handles interactions. |
| `assets/js/notes-data.js` | Generated by `scripts/simplify.sh`. Index of all notes and metadata (titles, dates, tags). Used for search and navigation on the archived static site. |
| `assets/js/theme-toggle.js` | Theme switcher. Toggles between light and dark mode, persists to localStorage. |
| `assets/js/webmcp.js` | Model Context Protocol tools. Agents can call `readNote` and `listNotes` to access note content (read-only). |
| `index.html` | Archived dashboard. Links to all notes, search box, settings. Not currently served. |
| `404.html` | Custom 404 page for the archived static site. |
| `tokens.css` | Design tokens. Colors, typography, spacing. Light/dark theme definitions. Used by the archived static site. |
| `ios/` | iOS app (archived). WKWebView wrapper around the static site. Not used since the site came down. Contains `NotesApp.swift` and `WebView.swift`. |

## Scripts

| File | What it owns |
|---|---|
| `scripts/simplify.sh` | Normalizes markdown structure and rebuilds `pages/` (archived). Ensures consistent formatting, updates the `notes-data.js` index, and validates links. Run after editing notes to prepare for deployment. |
| `scripts/sync-reminders.sh` | Syncs Apple Reminders to `notes/reminders.md`. Reads from the Reminders app via AppleScript and appends completed/pending reminders to the markdown file. Run periodically to keep reminders in sync. |
| `scripts/ship.sh` | Deployment script (archived). Calls `simplify.sh`, validates output, commits changes, and would push to GitHub. The site is no longer served. |
| `scripts/audit.sh` | Audit script. Checks for broken links, orphaned notes, missing TODOs, and style violations. |
| `scripts/monetize.sh` | Unknown purpose (possibly legacy). |
| `scripts/docs.sh` | Unknown purpose (possibly legacy). |

## Formatting conventions

- Plain markdown, no frontmatter
- Headings use `#`, `##`, `###` (not HTML tags)
- Lists use `-` for bullets, `- [ ]` and `- [x]` for tasks
- No emojis
- Links use `[text](path.md)` for internal wiki-style links (relative paths)
- Code blocks use triple-backticks with language hints
- Paragraphs are kept short; bullet points preferred over long prose

## Archived features

**Static site (notes.heyitsmejosh.com):** Was a fully rendered HTML dashboard with search, note browser, and styled note pages. Deployed via `wrangler pages deploy`. Site is archived but no longer served (taken down 2026-08-30). The static pages remain in `pages/` for reference.

**Brain graph:** Was a visual knowledge graph of key concepts from Claude memory. Moved to the separate `brain` repository (brain.heyitsmejosh.com/graph) in September 2026 to avoid route conflicts. The original `build.py` regenerated the graph from Claude memory; now the graph lives in `brain/public/graph/` and is maintained there.

## Gotchas

- **Reminders sync:** `sync-reminders.sh` appends to `reminders.md`, it does not replace it. Manual cleanup may be needed to avoid duplication if run multiple times on the same day.
- **No frontmatter:** Notes are plain markdown, no YAML/TOML metadata. To preserve metadata when syncing or migrating, metadata must be kept in file comments or as markdown sections (e.g., "updated: date" inline).
- **Link format:** Wiki-style relative links (`[text](path.md)`) work in Obsidian but may need adjustment if migrating to another system. The static site builder handles these specially.
